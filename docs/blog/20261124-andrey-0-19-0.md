# Datasets with overlapping variables

## TL;DR

- When studies, cohorts, or sites measure overlapping variable sets, their stacked table has
  block-wise missingness, and some pairs of variables are never jointly measured. A conditional
  independence test of such a pair, or a test that conditions on a variable measured only in
  another dataset, has no rows to use.
- The common answers each claim something the data did not show. Answering such a test with p = 1
  deletes true edges and creates false colliders; answering p = 0 draws an edge between every pair
  never jointly measured; imputation takes their covariance from a model, not from any row.
- Andrey 0.19.0 skips such a test: it neither removes an edge nor keeps one. A pair that no test
  can decide is left out of the graph and listed, an edge that a skipped test might have removed is
  listed too, and one log message reports both. With `possibly_separable="ambiguous"`, such an edge
  never creates a collider.
- On simulated cohorts of 20 to 50 variables with no complete rows, PC's graph made fewer errors
  than the empty graph in every setting and found 0.87 to 0.95 of the true edges between jointly
  measured variables. This was about as many as on the complete data; answering p = 1 found 0.21 to
  0.34.

---

Data often come from several datasets rather than one. A consortium pools cohorts from several
hospitals, a registry links tables collected by different agencies, and a lab combines panels run
years apart. Each dataset measures some variables that the others also measure, and some of its
own. The causal discovery literature calls this setting multiple datasets with overlapping
variables (Tillman et al., 2008; Tillman and Spirtes, 2011) or overlapping variable sets
(Triantafillou and Tsamardinos, 2015).

Take two studies of four variables. Both measure `W` and `Z`; the first also measures `X`, and the
second `Y`. Here are the first rows of each:

```{table}
:align: center

| X | W | Z |
|---:|---:|---:|
| 0.13 | 0.42 | 0.95 |
| -0.13 | -0.50 | -0.31 |
| 0.64 | -0.86 | -0.24 |
```

```{table}
:align: center

| W | Z | Y |
|---:|---:|---:|
| -0.39 | 0.53 | 1.65 |
| -0.28 | 1.11 | 1.49 |
| -1.24 | -0.63 | -0.33 |
```

When the studies are stacked into one table, each leaves a block of missing values (`NaN`) in the
column it did not measure:

```{table}
:align: center

| Study | X | W | Z | Y |
|---:|---:|---:|---:|---:|
| 1 | 0.13 | 0.42 | 0.95 | NaN |
| 1 | -0.13 | -0.50 | -0.31 | NaN |
| 1 | 0.64 | -0.86 | -0.24 | NaN |
| 2 | NaN | -0.39 | 0.53 | 1.65 |
| 2 | NaN | -0.28 | 1.11 | 1.49 |
| 2 | NaN | -1.24 | -0.63 | -0.33 |
```

This is block-wise missingness, not values missing at random across cells. Stacking datasets yields
a structured missingness pattern in which some variables are never jointly measured (Tillman and
Spirtes, 2011). Here, no row observes `X` and `Y`, so no test can check whether they are dependent.
For each test, PC and FCI use the rows where all its variables are observed, a procedure called
test-wise deletion. In this table, some tests have no rows, and how a method handles them
determines its graph.

## Tests with no rows

Consider the smallest case: two cohorts of 500 rows each from the fork `X <- Z -> Y`, one cohort
measuring `X` and `Z`, the other `Y` and `Z`. The true graph has two edges, and `X` and `Y` are
independent given `Z`. Because `X` and `Y` are never jointly measured, no test can check that
independence. A collider `X -> Z <- Y` can give both cohorts the same distributions, so these rows
cannot establish whether `X` and `Y` are adjacent. Every test of `X` and `Y` has no rows, as does
every test of `X` and `Z` given `Y`, or of `Y` and `Z` given `X`.

The same ambiguity holds in general. When some variables are never jointly measured, some of their
independences and dependences are unknown, so multiple graphs can fit every dataset (Tillman and
Spirtes, 2011). Methods built for this setting, ION (Tillman et al., 2008), IOD (Tillman and
Spirtes, 2011), and COmbINE (Triantafillou and Tsamardinos, 2015), combine what each dataset shows
and return all graphs consistent with them, or a summary of those graphs. COmbINE can even infer an
edge between two variables never jointly measured from constraints that the datasets impose
together. PC and FCI read a single table and do not combine datasets in this way.

## What the usual answers get wrong

**p = 1** treats a test with no rows as evidence of independence. It removes `X - Y`, which happens
to be right here, and then removes the true edges `X - Z` given `Y` and `Y - Z` given `X`. PC with
p = 1 returned the empty graph on 20 of 20 seeds. With `max_depth=0`, so no edge is tested given a
third variable, it returned the collider `X -> Z <- Y` on every seed: `X` and `Y` were separated
without `Z`, turning an untested pair into a collider.

**p = 0** treats a test with no rows as evidence of dependence. It keeps `X - Y`, an edge no row
supports, so PC returned the triangle on 20 of 20 seeds. On larger datasets with overlapping
variable sets, every pair never jointly measured becomes an edge. Those edges create false
colliders, from about 100 to over 1,000 per fit in the benchmark below.

**Imputation**, by EM or multiple imputation, fits a model over all columns to fill in the missing
values. Because no row observes `X` and `Y` together, their covariance comes from the fitted model,
not the data. After multiple imputation, any causal relation learned between variables never
jointly measured is right only if the assumed model gets that relation right; Structural EM, which
refits the model while filling in values, performed poorly on such data (Tillman et al., 2008).
Andrey's `missing="em"` rejects such data and names the pair.

**Dropping** every incomplete row leaves none. Dropping `X` or `Y` until every pair shares rows
discards a variable and its edges. On the benchmark cohorts, PC then found 0.42 to 0.75 of the true
edges between jointly measured variables.

## What Andrey does

- **Skips tests without enough rows.** A conditional independence test with fewer rows than needed
  (`|S| + 4` for Fisher's z, where `|S|` is the conditioning-set size), or with no degrees of
  freedom left, is skipped. It neither removes an edge nor counts as evidence of dependence.
- **Leaves out pairs that no test can decide.** When no test has enough rows to decide a pair, such
  as variables never jointly measured, the pair is omitted from the graph and listed in
  `metadata["undecided_pairs"]`. Orientation rules treat it as neither adjacent nor nonadjacent, so
  a triple whose endpoints form such a pair never becomes a collider.
- **Lists edges that a skipped test might have removed.** An edge is kept when no test with enough
  rows separated its endpoints, even if a skipped test, whose conditioning set was never observed
  with the pair, might have. `metadata["possibly_separable"]` lists these edges to show what the
  data could not test, not to mark them as false.
- **Keeps listed edges out of colliders on request.** PC, FCI, CD-NOD, FCI-JCI, the Markov-blanket
  searches, and PCMCI+ accept `possibly_separable="ambiguous"`, which treats any triple containing
  one of these edges as neither a collider nor a non-collider. The default, `"orient"`, orients it
  like any other triple.
- **Logs one summary message.** With the default `missing=None`, fitting on incomplete data logs
  one message per process. It names test-wise deletion, states when it is valid, and counts the
  pairs never jointly measured, the omitted pairs, and the listed edges, naming them when there are
  at most five.
- **Speeds up tests when missingness patterns are few.** Multiple datasets with overlapping
  variable sets have few missingness patterns. For Fisher's z and Student's t, a test sums each
  pattern's rows once when that is cheaper than scanning every row, and skips any conditioning set
  containing a variable never jointly measured with the pair before building it. On synthetic
  cohorts with overlapping variable sets, `pc` ran 2.5 to 6.6 times faster with identical graphs,
  and with `max_depth=None` it finishes on 40 and 50 variables.

PC, FCI, CD-NOD, FCI-JCI, the Markov-blanket searches, PCMCI, PCMCI+, and LPCMCI all skip such
tests and populate both lists; see the
[missing values guide](../docs/guides/missing-values.md#test-wise-deletion) for details on each
method.

Although no row is complete, PC recovers the true CPDAG: the collider at `Z` comes from `X` and
`W`, jointly measured in the first study, and `Z -> Y` follows because `W` and `Y`, jointly
measured in the second study, are independent given `Z`. `X` and `Y` are omitted from the graph and
listed in `undecided_pairs`.

All three edges appear in `possibly_separable` because each could have been removed by conditioning
on a variable measured only in the other study, which no row can test. Here all three edges are
true; on larger datasets with overlapping variable sets, the list also contains false edges. With
`possibly_separable="ambiguous"`, both sides of the collider are on the list, so the graph keeps
its edges without arrowheads. EM rejects the data and explains what would let it run.

## Benchmark on cohorts with overlapping variable sets

We simulated cohorts with overlapping variable sets from linear-Gaussian graphs of expected degree
3, drawing a new graph for each of 20 seeds and scaling columns to units between 0.1 and 100. We
tested three setups: 20 variables across 3 cohorts, 40 across 8, and 50 across 6, leaving 37, 144,
and 134 pairs never jointly measured. Some variables are measured in every cohort, some in several,
and a few in only one. The figure shows the missingness pattern for the 20-variable setup.

```{raw} html
:file: 0.19.0/pattern.html
```

We ran PC and FCI using Fisher's z and conditioning sets of up to 3 variables, holding the search
fixed while varying how tests without enough rows are answered. The table reports PC's structural
Hamming distance (SHD), averaged over seeds, when no row is complete and a tenth of the remaining
entries are missing at random. The empty graph's SHD equals the number of true edges.

| Variables (cohorts) | Empty graph | Andrey 0.19.0 | p = 1 | p = 0 | Complete data |
|---|---:|---:|---:|---:|---:|
| 20 (3) | 29.2 | 20.1 | 28.2 | 52.9 | 8.8 |
| 40 (8) | 62.7 | 49.2 | 66.0 | 187.8 | 14.7 |
| 50 (6) | 75.8 | 56.0 | 75.6 | 190.1 | 15.8 |

- Both PC and FCI beat the empty graph in all 12 settings with no complete rows (counting FCI's
  errors on its skeleton). With p = 1, PC's SHD was close to the empty graph's.
- With no complete rows, PC recovered 0.87 to 0.95 of the true edges between jointly measured
  variables, compared with 0.88 to 0.96 on complete data and 0.21 to 0.34 using p = 1.
- Across 1,204 PC and FCI fits on datasets with pairs never jointly measured, none of those pairs
  was drawn, and every one appeared in `undecided_pairs`.

The [release card](../docs/benchmarks/0.19.0.md#datasets-with-overlapping-variables) gives all
settings and intervals, along with results for dropping columns, false colliders, and time series.

## Limitations and trade-offs

- **True edges between variables never jointly measured are omitted.** Each fit had 5.8 to 12.7
  such edges. Because no row observes both endpoints, they are listed rather than drawn.
- **False edges remain, and `possibly_separable` does not isolate them.** A fifth to over a third
  of drawn edges are false. Most connect jointly measured variables whose separating set is never
  observed alongside them, so their dependence appears as a direct edge. Every
  such false edge is in `possibly_separable`, but so are 98 to 100% of all drawn edges. These false
  edges drive most false colliders: PC produced 12.8 to 81.3 per fit in the table's setting, versus
  5.2 to 18.4 on complete data.
- **`possibly_separable="ambiguous"` trades arrowheads for fewer false colliders.** It cut false
  colliders to at most 0.2 per fit for PC and 0.1 for FCI, but reduced recall of true arrowheads to
  0.00. PC then had higher SHD than the empty graph in all six settings, while FCI's skeleton
  errors rose by 0.5 to 4.4, remaining below the empty graph's. Keep the default when you need
  orientations, and use `"ambiguous"` when false colliders cost more than missing arrowheads.
- **A small fraction of complete rows tests cross-cohort pairs on tiny samples.** When 2 or 5% of
  rows are complete, every test has rows and overall SHD drops (17.6 versus 20.1 on 20 variables).
  Yet tests spanning cohorts rely solely on those few rows and can delete true edges: with 2%
  complete rows on 20 variables, PC found 0.63 of true edges between jointly measured variables,
  down from 0.87 with none.
- **Test-wise deletion assumes data missing completely at random.** Cohort membership is rarely
  random, and when missingness depends on other variables, testing only observed rows can yield
  wrong conclusions (Tu et al., 2019). Limiting conditioning-set size via `max_depth` never decides
  an unobserved pair; only rows observing both columns can.
- **Tests pool rows across cohorts.** Each test combines all cohorts that measure its variables
  into one sample. As Tillman and Spirtes (2011) note, pooling datasets into a single test often
  works worse in practice than combining per-dataset p-values, as IOD does.
